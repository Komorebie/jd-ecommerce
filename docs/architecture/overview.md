# 系统架构概览

last_updated: 2026-07-29
status: active

## 四层架构

```
┌────────────────────────────────────────────────┐
│                  前端展示层                      │
│  用户端 (user)  │  商家端 (merchant)  │  管理端 (admin)  │
├────────────────────────────────────────────────┤
│                  API 接口层                     │
│  /api/products  │  /api/orders  │  /api/users  │ ...  │
├────────────────────────────────────────────────┤
│                  业务逻辑层                      │
│  权限校验  │  订单状态机  │  退款流程  │  库存管理  │
├────────────────────────────────────────────────┤
│                  数据持久层                      │
│            Prisma ORM  →  PostgreSQL            │
└────────────────────────────────────────────────┘
```

## 路由组

| 路由组 | URL 前缀 | 角色 | 职责 |
|--------|----------|------|------|
| (user) | / | USER | 商品浏览、购物车、下单、退款申请、评价 |
| (merchant) | /merchant | MERCHANT | 商品管理、订单处理、退款审核、销售统计 |
| (admin) | /admin | ADMIN | 用户管理、商家管理、全平台订单、纠纷裁决 |

## 角色权限核心

| 订单状态 | USER | MERCHANT | ADMIN |
|----------|------|----------|-------|
| 待支付 | 取消/支付 | — | 查看 |
| 待发货 | 申请退款 | 确认发货 | 查看/强制取消 |
| 已发货 | 确认收货/申请退款 | 查看物流 | 介入处理 |
| 退款中 | 撤销申请(48h内) | 审核通过/拒绝 | 强制通过/拒绝 |
| 已完成 | 评价 | 回复评价 | 查看 |

# 测试规范

last_updated: 2026-07-29
status: active

## 测试分层

| 层级 | 工具 | 范围 | 覆盖率基线 |
|------|------|------|------------|
| 单元测试 | Jest + React Testing Library | 工具函数、组件逻辑 | ≥ 80% |
| API 测试 | Jest + fetch | 每个 API 端点 | 核心流程全覆盖 |
| E2E | 手动/AI 辅助 | 核心业务流程 | 订单+退款主流程 |

## 测试数据要求

- 测试数据必须覆盖边界情况（空值、极限值、非法输入）
- 订单测试覆盖所有状态转换路径
- 退款测试覆盖正常流程 + 超时/申诉等异常流程
- 权限测试确保每个角色只能访问其授权端点

## 命名

- 测试文件: `*.test.ts` / `*.test.tsx`
- 测试描述: "当[条件]时，应[结果]"

# API 错误码参考

last_updated: 2026-07-29
status: active

## 统一响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

## 错误码分类

| 范围 | 分类 | 说明 |
|------|------|------|
| 0 | 成功 | 操作成功 |
| 1xxx | 客户端错误 | 参数校验、权限等 |
| 2xxx | 业务错误 | 业务规则限制 |
| 3xxx | 服务端错误 | 内部异常 |

## 常见错误码

| code | message | 说明 |
|------|---------|------|
| 0 | 成功 | — |
| 1001 | 参数错误 | 请求参数格式或内容不正确 |
| 1002 | 未登录 | 需要登录后操作 |
| 1003 | 无权限 | 当前角色无此操作权限 |
| 1004 | 资源不存在 | 请求的商品/订单等不存在 |
| 2001 | 库存不足 | 下单时库存不够 |
| 2002 | 订单状态不允许 | 当前订单状态不支持此操作 |
| 2003 | 退款金额超限 | 退款金额不得超过实付金额 |
| 2004 | 超过操作时限 | 如超过48小时不可撤销退款申请 |
| 3001 | 服务器内部错误 | 未知服务端异常 |

## 使用方式

```typescript
// 成功
return NextResponse.json({ code: 0, message: 'success', data: result });

// 错误
return NextResponse.json({ code: 1003, message: '当前角色无此操作权限', data: null }, { status: 403 });
```
